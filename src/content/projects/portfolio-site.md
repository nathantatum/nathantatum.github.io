## Astrofy Portfolio & Tech Site

This site is built with [Astro v5](https://astro.build) — a modern static site framework designed for speed, zero client JS by default, and content-driven architecture.

### Highlights & Architecture
- **Astrofy Aesthetic**: Fixed responsive left sidebar with dark/light theme toggle.
- **Content Collections**: All projects, articles, experience items, and skills are driven strictly by Markdown and JSON files.
- **Static Output**: Built for fast hosting on GitHub Pages with static HTML compilation.
