## Raspberry Pi Setup & Utilities

Collection of scripts, configuration tools, and automation playbooks for bootstrapping fresh Raspberry Pi hardware.

### Features & Capabilities
- **Headless Setup**: Wi-Fi configuration and SSH key injection out of the box.
- **System Hardening**: UFW firewall rules, Fail2ban configuration, and automatic security updates.
- **Node Management**: Lightweight monitoring scripts for temperature, disk usage, and network connectivity.
