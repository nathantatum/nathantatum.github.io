This site is built with [Astro](https://astro.build) - a modern static site generator that ships zero JavaScript by default.

## Tech Stack

- **Framework**: Astro
- **Styling**: Vanilla CSS with custom properties
- **Fonts**: Inter + JetBrains Mono
- **Hosting**: GitHub Pages
- **CI/CD**: GitHub Actions
